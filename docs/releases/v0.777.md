# v0.777 upgrade notes

First public release, so there is nothing to upgrade from.

Apply it to a **clean or freshly installed Windows** for the best result. If you
are running an existing install, create a System Restore point first — several of
the options (Edge removal in particular) cannot be undone.

If you tried an earlier build of this playbook, re-run it with this version: the
"Keep …" options now actually restore the stock state instead of running nothing.
