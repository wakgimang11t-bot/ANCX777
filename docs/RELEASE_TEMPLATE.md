## ⬇️ Installation

Full walkthrough: **[Install guide](https://github.com/wakgimang11t-bot/ANCX777/blob/main/docs/INSTALL.md)**.

1. Create a **System Restore point**, or back up anything you cannot lose.
2. Download **`ANCX777.apbx`** from the assets below.
3. Check it against `ANCX777.apbx.sha256`:

   ```powershell
   Get-FileHash .\ANCX777.apbx -Algorithm SHA256
   ```

4. Drag the `.apbx` into [AME Wizard](https://amelabs.net), pick your options, run it, reboot.

**Requirements:** Windows 10 1809+ or Windows 11, and AME Wizard 0.8.4 or newer.
